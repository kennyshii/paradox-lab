01 The paradox

In a village, the barber shaves all and only the men who do not shave themselves. Does the barber shave himself? If he does, he’s a man who shaves himself, so the barber must not shave him. If he doesn’t, he’s a man who doesn’t shave himself, so the barber must shave him. Bertrand Russell found the same knot at the foundations of mathematics: take the set \(R\) of all sets that are not members of themselves. Is \(R\) a member of itself?

02 Make a guess

Is \(R = \{x : x \notin x\}\) a member of itself?

\(R \in R \iff R \notin R\). Naive set theory, which lets any property define a set, is inconsistent. Modern set theory (ZFC) avoids it by restricting which sets you’re allowed to form.

04 Why it works

Russell’s argument

Naive set theory has an unrestricted comprehension principle: for any property \(\varphi\), there is a set of exactly the things with that property. Take \(\varphi(x) = x \notin x\):

$$R = \{\, x : x \notin x \,\} \qquad\text{so for every } x:\quad x \in R \iff x \notin x.$$

Now let \(x\) be \(R\) itself:

$$R \in R \iff R \notin R.$$

A statement equivalent to its own negation is a contradiction, so naive set theory is inconsistent.

The diagonal picture

The membership grid in the lab shows why. \(R\)’s row is the diagonal with every entry flipped, so \(R\) disagrees with every set \(S_i\) at position \(i\). It can’t be any row of the table. If the table really listed all sets, \(R\) would have to be one of its rows, and the diagonal cell \((R, R)\) would have to equal its own opposite. This is the same diagonal argument Cantor used to show there are more real numbers than whole numbers.

Barber vs. Russell

The barber version is milder: it just proves that no such barber exists, a perfectly fine conclusion (a reductio). Russell’s version is a true antinomy because the offending set isn’t made up. It’s guaranteed to exist by a principle that seemed self-evident and that Frege had built his foundations of arithmetic on.

The fix

Zermelo–Fraenkel set theory (ZFC) replaces unrestricted comprehension with separation: you may only carve a subset out of a set you already have, \(\{x \in A : \varphi(x)\}\). Running Russell’s argument then just proves that \(\{x \in A : x \notin x\} \notin A\), so there is no set of all sets. Type theory, Russell’s own fix, forbids the question “\(x \in x\)?” altogether.
