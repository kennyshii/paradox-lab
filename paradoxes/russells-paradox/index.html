01 The paradox

In a village, the barber shaves all and only the men who do not shave themselves. Does the barber shave himself? If he does, he’s a man who shaves himself, so the barber must not shave him. If he doesn’t, he’s a man who doesn’t shave himself, so the barber must shave him. Bertrand Russell found the same knot at the foundations of mathematics: imagine the collection of every collection that doesn’t contain itself. Does that collection contain itself?

02 Make a guess

So who shaves the barber?

Every answer contradicts the rule, so the rule describes an impossible barber. Russell’s collection has the same problem, which is why mathematics now has stricter rules about which collections you’re allowed to make.

04 Why it works

  • 💈

    The rule can’t be followed

    Whatever the barber does about his own beard breaks the rule. So the rule describes a barber who can’t exist.

  • 📦

    The same trap in maths

    Ask for the collection of all collections that don’t contain themselves. Does it contain itself? Same loop as the barber.

  • 🏗️

    Mathematics got new rules

    Russell’s discovery forced mathematicians to set careful rules about which collections are allowed, so this one can’t be built.
