01 The paradox

Consider the sentence “This sentence is false.” If it is true, then what it says holds, so it is false. If it is false, then what it says (that it’s false) is correct, so it is true. Each answer forces the other. The argument uses nothing but the everyday rule that a sentence is true exactly when what it says is the case. So which rule of everyday reasoning has to give?

02 Make a guess

“This sentence is false.” Is it true or false?

Under the classical rules of truth, no consistent truth value exists. Logicians resolve it by changing the rules: truth-value gaps, a hierarchy of languages, or a logic that tolerates contradictions.

    04 Why it works

    • 🔄

      It flips forever

      If the sentence is true, it says it’s false. If it’s false, it’s telling the truth. Every answer turns into its opposite.

    • 🪞

      The problem is self-reference

      The sentence talks about its own truth. Most sentences talk about the world, like “snow is white”, and cause no trouble.

    • 🪜

      The fix: levels

      Logicians keep sentences and sentences about sentences on separate levels, so no sentence can judge itself.
