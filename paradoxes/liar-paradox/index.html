01 The paradox

Consider the sentence “This sentence is false.” If it is true, then what it says holds, so it is false. If it is false, then what it says (that it’s false) is correct, so it is true. Each answer forces the other. The argument uses nothing but the everyday rule that a sentence is true exactly when what it says is the case. So which rule of everyday reasoning has to give?

02 Make a guess

“This sentence is false.” Is it true or false?

Under the classical rules of truth, no consistent truth value exists. Logicians resolve it by changing the rules: truth-value gaps, a hierarchy of languages, or a logic that tolerates contradictions.

    04 Why it works

    The T-schema

    Tarski’s classic principle about truth says that for any sentence \(S\) that asserts \(p\):

    $$S \text{ is true} \iff p.$$

    The liar \(L\) asserts “\(L\) is false”, i.e. \(p = \lnot T(L)\). Plugging in gives

    $$T(L) \iff \lnot T(L),$$

    which has no solution in two-valued logic. That is exactly what an empty truth table means: no row survives.

    Loops, not just self-reference

    Self-reference alone isn’t the culprit. The truth-teller “This sentence is true” is self-referential but has two consistent rows: it’s underdetermined rather than contradictory. And a liar can be spread across several sentences (“The next sentence is true.” “The previous sentence is false.”): no single sentence talks about itself, yet the cycle as a whole has an odd number of negations and no consistent assignment. Sentences that bottom out in facts about the world (“Snow is white”) are grounded and get exactly one value.

    Why it’s an antinomy

    Every premise looks like basic logic: sentences are true or false, and the T-schema holds. Yet together they produce a contradiction. Proposed resolutions all give something up:

    • Hierarchy (Tarski): a language can’t contain its own truth predicate; “true” for level-\(n\) sentences lives at level \(n+1\).
    • Truth-value gaps (Kripke): ungrounded sentences like the liar get no value at all.
    • Dialetheism (Priest): accept that the liar is both true and false, using a paraconsistent logic so the contradiction doesn’t spread.

    The same diagonal trick powers Gödel’s incompleteness theorems and Russell’s paradox, which is next door.
